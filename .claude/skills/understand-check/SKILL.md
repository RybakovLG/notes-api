Формат чередуется: «вопрос / мини-задача / объясни как новичку»

Количество вопросов 5.

Критерии успешной проверки правильные ответы на все вопросы / мини-задача решена на 100% / объяснение понятно даже новичку. 

Можно добавлять вопросы в процессе ответов, если есть неточности или ответы неверные.

Без подсказок.

При провале дается краткий ответ с предложением попробовать еще раз, на да - вызвать этот навык снова с другим форматом.
